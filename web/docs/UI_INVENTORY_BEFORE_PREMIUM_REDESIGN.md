# UI inventory before premium redesign

This inventory freezes the trusted TradeMentor interface as the functional baseline.

## No-regression checklist

- Preserve Wallet, Positions, Risk, Aster, Hyperliquid, strategies, history, charts, calendar, performance, support and administration.
- Preserve all financial position fields, close controls, responsive mobile navigation, themes and PWA behavior.
- Keep authenticated user data isolated and retain the existing interface as a safe fallback.
- Never add a trading side effect to presentation or interface switching.
